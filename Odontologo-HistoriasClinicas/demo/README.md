# Consultorio Bertil — Historias Clínicas (demo)

Demo del sistema de historias clínicas digitales para consultorio odontológico. Incluye registro de pacientes, historial de tratamientos por consulta, fotos y radiografías, y acceso mediante login.

Vista de demostración con datos ficticios — ningún dato aquí corresponde a personas reales. El registro de nuevos pacientes se guarda en el navegador (localStorage) solo para esta demo; el sistema en producción usará una base de datos real.

**Ver la demo en vivo:** se activa desde GitHub Pages una vez publicado este repositorio.
